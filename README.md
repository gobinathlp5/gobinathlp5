### 📡 CAN Bus — Simulation of CAN Protocol
> **C | Arduino UNO | MCP2515 | Automotive Communication**

A hardware-level simulation of the **Controller Area Network (CAN) protocol** — the backbone of modern automotive and industrial embedded systems.

**What I built:**
- Implemented CAN communication between **two Arduino UNO boards** using MCP2515 CAN controllers
- Transmitted real-time **temperature and humidity sensor data** over the CAN network
- Demonstrated **message arbitration, priority handling**, and reliable data transfer

**Why it matters:**  
CAN bus is used in every modern vehicle's ECU network. This project gave me hands-on experience with automotive-grade communication — directly relevant to embedded systems research.
